    전용 도구로 준비한 계정을 가져옵니다. 이 도메인에서 10분 동안 한 번 사용할 수 있으며, 기존 계정은 덮어쓰지 않습니다.

    로그인 화면 설정주소와 로그인 요소를 지정하세요

    정확히 일치하는 도메인에만 적용합니다. 하위 도메인은 따로 등록하세요.

    허용 도메인의 모든 화면에 계정 버튼을 표시하고, 로그인할 때 지정한 세 요소를 사용합니다. 계정 전환은 사이트의 로그아웃 버튼을 누른 뒤 로그인하고 원래 주소로 돌아옵니다. 자동 매핑이 어려우면 요소를 직접 선택하거나 CSS 선택자를 입력하세요.

    세션과 지원 범위

    현재 탭에서 로그인합니다. 업무 화면에서는 저장된 로그인 주소로 이동한 뒤 로그인합니다.

    일반 창의 탭들은 로그인 상태를 공유합니다. 확장 세부정보에서 ‘시크릿 모드에서 허용’을 켜면 시크릿 창에서도 사용할 수 있습니다. 일반 창과 시크릿 창의 웹 세션은 분리되고, 시크릿 창끼리는 공유합니다. 계정 보관함은 함께 사용합니다.

    OTP·CAPTCHA·SSO 추가 인증은 사이트에서 직접 완료해주세요. iframe·닫힌 Shadow DOM·단계가 나뉜 로그인은 지원하지 않습니다.
