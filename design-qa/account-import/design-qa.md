# 암호화 계정 가져오기 검증

26.11.03. 로그인 확장 1.1.1의 DAL-09를 검증했다. 기존 화면 구성과 접근 권한을 유지하고, 도메인별 일회용 요청과 암호화 파일 가져오기를 추가했다.

## 결과

- 단위 검사 9건 통과. 기존 보관함 4건과 전달 암호화·만료·변조·origin 결합·중복 거부 5건을 포함한다.
- 실제 MV3 Chromium의 가져오기 검사 8개 묶음 통과. 요청 다운로드→암호화 JSON 선택→4개 합성 계정 저장→재열기와 실제 로그인 폼 제출을 확인했다.
- 같은 요청 재사용, 중복 계정 일괄 가져오기, popup/content의 관리 메시지를 거부했다. 실패 후 기존 4개 계정을 보존했고 잠금 후 요청을 폐기했다.
- 기존 브라우저 회귀 15개 묶음 통과. 계정 CRUD, 요소 선택, 로그인 제출, 비허용 도메인, 시크릿 세션 경계와 페이지 오류를 확인했다.
- 1920×1080과 390px 폭의 실제 관리 화면을 열어 검토했다. 기존 계정 중심 배치를 유지하고 가로 넘침이 없었다. 새 가져오기 영역은 접힌 보조 작업이다.
- 구문·manifest/권한 검사와 패키징 통과. 로그인 ZIP은 runtime 13개 파일이며 기존 검사기는 13개다. 새 외부 연결·host 권한은 추가하지 않았다.
