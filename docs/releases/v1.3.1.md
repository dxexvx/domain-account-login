# 도메인 계정 로그인 1.3.1

Chrome 확장 세부정보에 **시크릿 모드에서 허용** 옵션이 표시되도록 수정했습니다. 사용하려면 직접 켜세요. 기본 로그인 방식은 현재 탭이며, 보관함은 일반 창과 시크릿 창에서 공유합니다.

## 다운로드·설치

1. 아래 Assets에서 **domain-account-login-1.3.1.zip**을 다운로드합니다.
2. 유지할 위치에 압축을 풀고 **domain-account-login** 폴더를 둡니다.
3. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램 로드** → 압축을 푼 **domain-account-login** 폴더를 선택합니다. 이 폴더 바로 안에 `manifest.json`이 있어야 합니다.
5. 확장 아이콘 → **계정보관함 열기**에서 도메인과 계정을 등록합니다. 로그인 화면의 **자동 매핑**을 이용할 수 있습니다.

Chrome Web Store를 통한 원클릭 설치는 제공하지 않습니다. 설치에는 npm·Python·빌드가 필요 없습니다. ZIP 안의 README.md·INSTALL.md·MANUAL.md에 상세 안내가 있습니다.

## 기존 설치 업데이트

기존 확장을 제거하지 마세요. Chrome에 등록된 기존 폴더에 ZIP의 파일을 덮어쓰고 확장과 대상 사이트를 새로고침합니다. 설치 폴더를 유지해야 기존 ID와 저장 계정이 유지됩니다. 경로를 옮기려면 먼저 계정 백업을 내보내고 새 설치로 가져오세요.

첨부한 **SHA256SUMS.txt**로 ZIP의 SHA256을 확인할 수 있습니다. 개인 계정·비밀번호·브라우저 프로필은 포함하지 않습니다.
