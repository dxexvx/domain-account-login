# 도메인 계정 로그인 1.5.0

기준 도메인의 계정을 함께 쓸 **여러 도메인을 직접 추가·수정·제거**할 수 있습니다. 로그인 페이지는 **/login 같은 경로**로 설정하고 각 접속 도메인·포트에서 사용합니다.

## 변경 사항

- localhost 공유 체크박스를 **함께 사용할 추가 도메인** 목록으로 바꿨습니다. 입력을 고치거나 제거한 뒤 **도메인 저장 · 접근 허용**으로 반영합니다. 왼쪽에도 기준 도메인 아래 추가 도메인이 표시됩니다.
- 추가 도메인은 같은 계정과 로그인 요소를 공유합니다. `https://dev.example.com`, `http://localhost:3000`처럼 정확한 주소를 각각 등록합니다. `localhost:*`는 모든 localhost 포트를 뜻하는 목록 항목입니다.
- 로그인 페이지 입력에는 경로·쿼리·해시만 표시합니다. 로그인과 원래 화면 복귀는 현재 도메인·포트에서 수행합니다.
- 1.4.0에서 켠 localhost 공유는 목록의 `localhost:*`로 이어집니다. 기존 도메인 ID·계정·로그인 요소·버튼 위치를 유지합니다. 추가 도메인에서 자동 매핑해도 기존 그룹을 갱신합니다.
- 백업에 추가 도메인 목록을 포함합니다. 기존 그룹에 병합할 때 현재 설정을 유지하며 중복 공유 충돌은 거부합니다.

## 사용 조건

등록한 도메인의 로그인 경로와 요소가 같아야 합니다. 정확한 도메인 설정은 `localhost:*`보다 우선합니다. 외부 도메인의 wildcard는 허용하지 않습니다. 저장 계정을 사용할 앱만 추가하세요. 자세한 방법과 주소별 우선순위는 동봉한 MANUAL.md를 확인하세요.

## 다운로드·업데이트

Assets의 **domain-account-login-1.5.0.zip**과 **SHA256SUMS.txt**를 사용하세요. ZIP을 풀면 manifest.json·README·INSTALL·MANUAL이 들어 있는 **domain-account-login** 폴더가 나옵니다.

기존 설치 폴더를 유지해 파일을 반영하고 `chrome://extensions`에서 확장을 새로고침하세요. 기존 확장을 제거하지 마세요. 새 설치는 Chrome 개발자 모드의 **압축해제된 확장 프로그램 로드**에서 해당 폴더를 선택합니다. Chrome Web Store 설치는 제공하지 않습니다.
