# 도메인 계정 로그인 1.4.0

BARO 등 기존 도메인에 저장한 계정을 **localhost의 모든 포트에서 함께 사용**할 수 있습니다. 계정과 비밀번호를 포트마다 다시 등록할 필요가 없습니다.

## 변경 사항

- 도메인별 **localhost:* 계정 공유** 옵션을 추가했습니다. 기본 해제이며 한 도메인만 공유 원본으로 선택합니다.
- http·https localhost의 모든 포트에서 원본 계정 목록·로그인 요소를 사용합니다. 로그인과 원래 화면 복귀는 현재 로컬 포트에서 수행합니다.
- localhost에 별도 등록한 계정은 공유 계정보다 우선합니다. 다른 호스트와 127.0.0.1에는 공유하지 않습니다.
- 계정 백업에 공유 설정을 포함합니다. 기존 도메인의 설정은 유지하며 공유 원본 충돌은 저장 전에 거부합니다.

## 사용 방법

확장 설정 → 기존 **https://baropro.vrixon.com** 도메인 → **로그인 화면 설정** → **localhost:*에서 이 도메인의 계정 공유** 선택 → **도메인 저장 · 접근 허용**. localhost 페이지를 새로고침하면 기존 계정 버튼을 사용할 수 있습니다. 로컬 앱의 로그인 경로와 요소는 원본 설정과 같아야 합니다. 선택한 계정으로 로그인할 때만 로그인 정보를 입력합니다. localhost 쿠키는 포트 간 공유될 수 있습니다.

## 다운로드·업데이트

Assets의 **domain-account-login-1.4.0.zip**과 **SHA256SUMS.txt**를 사용하세요. ZIP을 풀면 manifest.json·README·INSTALL·MANUAL이 들어 있는 **domain-account-login** 폴더가 나옵니다.

기존 설치 폴더를 유지한 채 파일을 반영하고 `chrome://extensions`에서 확장을 새로고침하세요. 기존 확장을 제거하지 마세요. 기존 ID와 계정을 보존합니다. 새 설치는 Chrome 개발자 모드에서 **압축해제된 확장 프로그램 로드**로 해당 폴더를 선택합니다. Chrome Web Store 원클릭 설치는 제공하지 않습니다.
