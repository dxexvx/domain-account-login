# 도메인 계정 로그인

도메인별 여러 계정을 저장하고, 허용 사이트의 어느 화면에서든 플로팅 계정 버튼으로 현재 탭에 로그인하는 Chrome 확장입니다. 축약 계정을 세로로 표시하며 전체 별칭 툴팁, 드래그 이동, 목록 접기·펼치기를 지원합니다.

[설치·에이전트용 절차](../../README.md) · [간단 매뉴얼](MANUAL.md)

Chrome에서 이 폴더를 압축해제된 확장으로 로드하세요. 빌드가 필요하지 않습니다.

설정 상단에서 전체/현재 도메인의 계정을 암호화 파일로 내보내고 다른 프로필에 가져올 수 있습니다. 백업 암호를 사용하며 기존 아이디와 겹치는 계정은 유지합니다. [백업 사용법](MANUAL.md#계정-백업-파일)을 참고하세요.
